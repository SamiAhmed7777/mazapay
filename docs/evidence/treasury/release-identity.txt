# Release identity — treasury publication

This note records the git identity of the tree it ships in. It is deliberately
written so a reviewer without `.git` can verify it: `git-tree.txt` in this
directory lists every tracked file with its git blob sha1, and a git blob id is
`sha1("blob <length>\0" + file bytes)`, so each listed hash can be recomputed
from the files themselves.

The commit above — `28478bc` — is the A-graded treasury change set
(`urn:ump:bxgqmve6phf7t5hzyvsgxccjhxyyvon6sp3laztt5lgdrxlpeiqq`). The evidence
files in this directory carry a sha256 manifest of every file under `mazapay/`
and `tests/`, so graded bytes and shipped bytes can be matched file by file.

## Revision added by this note
